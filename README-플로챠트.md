# 플로챠트 — 화면별

> 동작을 바꾸면 그 화면 문서도 같은 커밋에서 고칩니다.

| 화면 | 문서 | 담은 것 |
|---|---|---|
| 홈 | [플로챠트/홈.md](플로챠트/홈.md) | '하루에 다녀올 만한 곳' 10곳 · 더 보기 · 내 위치 기준과 '↻ 다시 찾기' · 별점 집계(결정 ❶~❹) · 이동 시간 |
| 지도 | [플로챠트/지도.md](플로챠트/지도.md) | 처음 보여 줄 곳 · 시/도 · 시군구 · 이름 검색 · '↻ 내 위치 다시 찾기'(가까운 100곳) · 겹치는 마커는 모든 모드에서 '+N' 대표 묶음(누르면 목록) |
| 추천 | [플로챠트/추천.md](플로챠트/추천.md) | 추천 장소(시간 · 날씨 · 취향 점수, 10곳씩 더 보기) · 추천 코스(조건 · 정렬, 서버에서 10개씩 더 보기) |
| 새 여행 만들기 | [플로챠트/여행-만들기.md](플로챠트/여행-만들기.md) | 내 여행 → ① 일정(자동 제목 · 중복 순번, 저장 안 함) → ② 규칙(이동수단 · 여기서 저장) → 추천 5곳 자동 담기(밥집 2 · 카페 1 · 명소 2) · 최단 동선 → 타임라인 |
| 장소 업데이트(서버) | [플로챠트/장소-업데이트.md](플로챠트/장소-업데이트.md) | TourAPI 수집(`collect.mjs`) → DB 반영(`load.mjs`) · 연동 로그 · 사라진 장소 정리(`hidden_at`) |
